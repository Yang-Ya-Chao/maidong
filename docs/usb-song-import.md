# U盘加歌与固定保存目录

手动添加歌曲和应用下载歌曲统一使用：

`U盘根目录/maidongktv/video/cloud-song/`

例如：`周杰伦-晴天.MKV`。文件扩展名大小写均可，命名按“歌手-歌名”解析。

把第三方歌曲复制到这个已有保存目录后，点击“U盘加歌”即可重新扫描并刷新搜索。无需选择目录，也无需额外创建导入文件夹。扫描会读取已连接U盘的固定保存目录；插入或拔出U盘也会刷新歌曲列表。扫描本身不会创建目录。

新导入歌曲加入搜索结果，可按歌手、歌名、文件名、拼音或首字母检索。主搜索、快捷搜索和手机点歌查询使用相同的搜索入口。

U盘发现使用系统可移动卷、应用外部存储位置以及当前进程可见的系统挂载信息，不按FAT32限制文件系统。系统已挂载且App可读的NTFS、exFAT和厂家FUSE挂载也可作为候选路径。挂载识别与目录扫描不要求U盘可写；选择下载到U盘时才检查写入权限。多U盘加歌扫描全部已发现U盘，选择下载目标时可选择U盘，但不能另选歌曲目录。

验证：Debug APK构建与本地单元测试覆盖歌曲命名/搜索/分页、多格式挂载信息解析、固定目录扫描和扫描不创建目录。这些不是实机兼容性验证；文件管理器能访问不等于App必然具备相同权限，真实设备的NTFS/exFAT读取和播放仍需实盘验收。
