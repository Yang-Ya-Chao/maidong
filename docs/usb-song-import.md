# U盘加歌与固定保存目录

手动添加歌曲和应用下载歌曲统一使用：

`U盘或内存卡根目录/maidongktv/video/cloud-song/`

手动加歌例如：`周杰伦-晴天.MKV`。文件扩展名大小写均可，命名按“歌手-歌名”解析。

应用下载的歌曲无需改名：扫描读取同名的 `.complete.json` 完成记录，按歌曲编号匹配曲库，还原歌名、歌手及声道信息；完成记录中保存的曲目信息也可在曲库不可用时使用。仅保留编号媒体文件时，按文件名中的编号匹配现有曲库，例如 `00522920.mkv`；其他供应商文件名按曲库文件名匹配，不区分大小写。移动歌曲时建议同时保留完成记录。搬到新存储卷后使用文件当前路径播放。

把第三方歌曲复制到这个已有保存目录后，点击“U盘加歌”即可重新扫描并刷新搜索。无需选择目录，也无需额外创建导入文件夹。扫描会读取已连接外置存储的固定保存目录；插入或拔出外置存储也会刷新歌曲列表。扫描本身不会创建目录。

新导入歌曲加入搜索结果，可按歌手、歌名、文件名、拼音或首字母检索。主搜索、快捷搜索和手机点歌查询使用相同的搜索入口。

U盘发现使用系统可移动卷、应用外部存储位置以及当前进程可见的系统挂载信息，不按FAT32限制文件系统。系统已挂载且App可读的NTFS、exFAT和厂家FUSE挂载也可作为候选路径。挂载识别与目录扫描不要求U盘可写；选择下载到U盘时才检查写入权限。多U盘加歌扫描全部已发现U盘，选择下载目标时可选择U盘，但不能另选歌曲目录。

内存卡使用相同扫描、下载和空间检查流程。Android 7–10 通过公开卷 UUID 补充挂载路径，较新系统使用卷目录，同时补充 `/storage` 下可读的公开卷和厂家挂载路径；内部模拟存储不作为外置卡。旧设备以实体可移动 SD 卡作为主共享存储时，也允许使用。系统不可见或应用没有读取权限的卡无法通过路径发现获得额外权限。[Android StorageVolume API](https://developer.android.com/reference/android/os/storage/StorageVolume)

本地单元测试覆盖歌曲命名/搜索/分页、编号下载与完成记录识别、歌曲移动后的路径、多格式与SD卡挂载信息解析、固定目录扫描和扫描不创建目录。这些不是实机兼容性验证；文件管理器能访问不等于App必然具备相同权限，真实设备的NTFS/exFAT和SD卡读取、下载及播放仍需实盘验收。
