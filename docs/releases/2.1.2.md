# 麦动 KTV 2.1.2

本次版本仅包含以下两个 issue 的修复，基于远端 feature/igeba-media 构建。

- [IKQ63V](https://gitee.com/yangyachao-X/maidong-ktv/issues/IKQ63V)：扫码点歌优先使用当前 Wi-Fi 或有线网络的 IPv4 地址，排除 Wi-Fi Direct、VPN 和蜂窝接口；支持无互联网的局域网，网络切换后重新生成二维码并恢复本地服务。
- [IKQ4S6](https://gitee.com/yangyachao-X/maidong-ktv/issues/IKQ4S6)：替换原来的深色空白 TV banner，提供含麦克风标识和“麦动 KTV”文字的 320×180 横幅，并在应用和主入口声明 banner。

版本：2.1.2；versionCode：5。安装包包含 armeabi-v7a 和 arm64-v8a。Gradle 生成 Release 包后，使用外部正式密钥（别名 YYC）重新签署；签名证书 SHA-256 为 37bf40eff1361ea6c352f8348003796663315b48cb2febaab0a2212c46387a0c，与 Gitee 2.1.1 完全一致。密钥及密码不纳入源码仓库。

安装包：Maidong-KTV-2.1.2.apk；SHA-256：864c4ff2e679aabc1ff8742b32260df8cbf271ffef203ddd3cba5d81422e77fa。

单元测试：82 项全部通过，其中 8 项覆盖地址选择、Wi-Fi Direct/VPN 排除、无互联网局域网及空网络输入。独立执行 assembleRelease 成功。正式签名包已在 API 25 模拟器成功覆盖旧版并启动；日志记录播放器首帧与播放状态，未将此视为目标盒子验收。lintRelease 任务成功结束，但项目配置 abortOnError=false，报告仍有 81 errors、3510 warnings、29 hints，不能视为零问题检查。SlimBox 14.23 / X96 M200 与报告者原局域网的实际表现需要原设备确认。

构建配置：为 Kotlin 编译器设置 2 GiB 堆上限，避免完整编译时继承默认 512 MiB 并持续垃圾回收。不改变应用运行时内存配置。
