# 麦动 KTV 2.1.1

- 默认自动选择解码器，无需在设置中选择解码模式；忽略旧的手动偏好。
- 音视频解码失败时分别尝试备用路径，限制重复恢复；路径耗尽后交由歌曲队列跳过。
- 修复解码重建后的 Surface 连接与画面停滞问题，增加播放就绪但未出首帧的恢复检查。
- 改善部分 MKV 索引异常、MPEG-4 等样本的兼容性；开机启动默认关闭。

验证：此前 Debug 构建与单元测试通过，全自动模拟器回归 8 个 MKV 样本，5 个通过、3 个仍受编码或文件异常限制，无进程崩溃。详见 decoder-validation/README.md。不宣称所有 MKV 配置均支持。
