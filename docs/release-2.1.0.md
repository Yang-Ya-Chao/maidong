# 麦动 KTV 2.1.0

本次发布将 OpenList 网盘需求与 2.0.1 修复合并到 `feature/igeba-media` 分支。

## 新增与修复

- 支持 OpenList 网盘连接、歌曲扫描、点播及上传保存；配置入口位于“设置 → 数据设置 → 网盘设置”。
- 本地、U 盘、网盘统一扫描、检索与保存。保存位置选择网盘时，“U盘加歌”显示为“网盘加歌”，点击“立即加歌”建立本地索引。
- 修复应用下载的数字编号文件显示为编号的问题：优先使用曲库文件名关联歌名与歌手，同时兼容下载记录。外部歌曲按 `歌手-歌名` 解析，两类文件均可检索。
- 补充可移除内存卡和旧 Android 存储卷识别。U 盘与内存卡使用所选卷的 `maidongktv/video/cloud-song` 目录。
- 播放画面固定按 16:9 布局。
- 启动使用内置曲库，不自动同步曲库或从 Gitee 下载数据库；点击“曲库更新”时检查 i歌霸列表，有变化则同步，无变化则提示已是最新。保留应用版本接口检查。

## 使用说明

- 默认歌曲目录：`/storage/emulated/0/MaidongKTV/video/cloud-song`。
- 外部歌曲命名示例：`刘若英-后来.mkv`；应用下载的编号文件保持原名即可。
- 网盘扫描建立索引，不会自动把整盘歌曲下载到设备；播放需要服务与文件可访问。
- 网盘保存需要上传权限；具体配置见 [OpenList 说明](openlist.md)。
- 内存卡需要系统已挂载并允许应用读取、写入；旧设备的权限与历史目录兼容情况见 [存储说明](usb-song-import.md)。
