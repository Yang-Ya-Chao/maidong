# 点歌及下载状态修复

- 点击云端歌曲后，pendingQueueSongIds 立即参与已点状态判断，列表立即刷新。右侧已点图标优先于下载状态，完成前不等待实际播放队列插入。失败后撤销待加入状态，允许用户重新点歌。
- 下载器提供线程可见的已读字节数、总量和平均传输速度。顶部每秒刷新下载歌曲、百分比和 KB/s 或 MB/s；有当前/下一首时追加显示，无播放信息时单独显示下载。首页、子页、全屏共用文字；超宽文字持续横向滚动，滚动位置不因每秒状态更新而重新起步。
- 下载失败先释放下载注册状态，再通知界面。待播放的失败歌曲退出自动播放队列；若当前正等待该歌曲，跳到后续歌曲。正在播放的歌曲另行保存失败不会触发切歌。
- 重启恢复失败、暂停、中断任务时，不将其作为自动播放队列任务恢复。保留失败记录供下载列表手动重试或删除。原下载列表已存在删除按钮及任务/缓存清理路径，本次复用，未增加自动删除媒体文件的策略。

## 手动验收

1. 点未下载歌曲，右侧立即成为已点图标，顶部显示下载名、百分比、速度；再点另一首，两个点歌意图均保留。
2. 已有歌曲播放时再点云端歌曲，当前/下一首后跟下载信息并滚动；下载结束后提示消失。
3. 用不可用歌曲地址触发下载失败，再点可用歌曲，确认后者仍能下载；失败记录可重试或删除。
4. 退出重开，失败记录不自动重新下载或占住播放队首；删除后重启不再出现。
5. 遥控器焦点、暂停/继续、U盘下载及 OpenList 保存仍需实际设备回归。
