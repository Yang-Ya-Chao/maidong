## 请求方式

统一 POST http://app.ige8.net/cloud.php，表单编码，PARAMS 为 JSON 字符串。

歌单列表：

```text
VER=6
CMD=GET_PACGS
PARAMS={"PackageType":3,"Filter":"","Page":{"PageNo":1,"PageSize":100}}
```

歌单详情：

```text
VER=6
CMD=GET_SONGS
PARAMS={"UserId":0,"Filter":{"Package":{"Type":3,"Id":"51890"}},"Page":{"PageNo":1,"PageSize":50}}
```

PackageType=1为歌手、3为公开歌单、4为榜单。全曲库分页使用已验证的 Order:[{"SongName":0}]，默认排序曾发生跨页重复和遗漏；同步仍需核对唯一编号数。

目录歌曲字段包括 SongNumber、SongName、SingerName、LanguageName、FileName、Version、Duration、VoiceChannel。用 SongNumber 请求媒体地址，不能把 FileName 当作歌曲编号或自行拼接下载地址。歌曲编号必须按字符串保存，保留前导零，例如00522920。

## 麦动接入边界

新目录直接提供新源编号，新歌曲无需旧编号映射。旧收藏、历史、自建歌单引用的是旧库ID，迁移时需按歌曲名称、歌手、版本核对；存在多个候选时不能自动选首项。未匹配项保留原元数据，以免用户记录消失。

目录可访问与完整歌曲可播放是两项独立验证。此次没有验证63个歌单全部歌曲的媒体有效性，也没有确认Android播放器兼容性。

新分支已有目录缓存及部分适配代码，整个应用的下载、播放器和所有入口切换尚未完成构建与运行验收。已有页面及布局继续保持。
