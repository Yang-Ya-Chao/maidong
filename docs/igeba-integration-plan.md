- 外部catalog.json只保留带新源编号的导入条目，移除旧源条目及临时媒体地址。

## 会话与媒体

公开目录为cloud.php的GET_SONGS/GET_PACGS，可匿名查询。媒体地址为telnet.php的GET_SONGADDR。未实现随机身份、账号轮换或伪造身份。

应用默认UserId=0。确需本人正常会话时，配置设备文件MaidongKTV/igeba_session.json：

```json
{"UserId": 0}
```

0是匿名示例；仅填写本人有权使用的身份，不将账号ID或临时媒体地址提交到仓库。接口Code不能单独证明身份真实性；下载还会核对媒体服务器的真实响应。

已知样本为MKV、H.264视频、双Vorbis音轨。目录访问成功不证明所有媒体可用；原伴唱顺序仍需要实际试听确认。原高清入口目前没有权威分辨率字段可用于全面分类，不能把目录字段当作真实高清证明。
