# 麦动 KTV 2.0.0 曲库与存储架构

分支：`feature/igeba-media`。本文件描述当前分支结构，运行验收记录见 [电视与存储验证](tv-storage-mobile-verification.md)。

## 当前数据

- `igeba_catalog.db`：仅包含新版目录，含 81,801 首歌曲、4,807 位歌星、63 个分类歌单、7 个排行榜及关联关系。APK 直接携带此数据库。
- `singer_portraits.db`：独立保存 68,314 条歌星名称与图片地址映射。保存的是图片地址，未将所有图片离线打包。
- `personal_media.db`：独立保存个人歌曲快照；收藏、自建歌单引用、设置、队列及历史继续通过本地状态保存。
- `IgebaCatalog` 保留现有页面查询契约，提供歌曲、歌星、分类、排行榜、拼音和首字母查询。

## 个人数据迁移

- 旧收藏只在歌名和歌手唯一匹配时关联新版歌曲编号；歧义记录保留元数据，不自动挑选版本。
- 设备上的旧数据库只用于一次性个人记录及歌星图片迁移，保存并回读核对后删除；迁移失败时保留文件用于恢复。
- 找不到歌曲元数据的引用保留原 ID 及“已失效歌曲”标记。
- 个人快照不持久化旧媒体下载地址。
- 保留 `PersonalMediaMigration`、`SingerPortraitStore` 和歌星图片提取工具是为了升级兼容；分支不再携带旧公共曲库及其网络分发文件。

## 下载、播放与存储

- 新目录编号按字符串保存前导零，不从文件名推导歌曲编号。
- 下载使用有界 Range 分段，校验 Content-Range 与分段长度，保留进度、暂停、重试及断点恢复。媒体可用性以服务器响应为准。
- 播放使用 Media3，保留现有页面、小窗与全屏控制，以及原唱和伴唱切换。
- 本地下载路径保持 `/storage/emulated/0/MaidongKTV/video/cloud-song`。
- U 盘下载路径为所选卷根目录下的 `maidongktv/video/cloud-song`；扫描从 `maidongktv` 目录加载本地歌曲。
- 默认本地存储；选定 U 盘不可用、不可写或空间不足时回退本地，保留用户的 U 盘偏好。
- 首次升级清理旧下载缓存；重置曲库清理本机缓存和下载歌曲，恢复 APK 内置曲库，不处理 U 盘文件。

## 分支清理

已移除旧数据库分片及分发清单、旧歌源 JS 和接口探测脚本、旧 IJK Java 与原生库、空置旧接口文件，以及旧曲库分发 BuildConfig 和 IJK 混淆规则。

README 中的运行说明以当前分支为准。`docs` 中带时间和 APK 哈希的记录是历史验证证据，不代表之后每次构建都完成了同样的设备验收。
