# 电视界面等比例适配

电视端以现有 1280×720 布局为基准，按应用实际渲染画面的宽高统一计算 UI 密度。XML 的 dp/sp、程序生成的按钮和列表、弹窗及自绘音量控件使用同一 Activity 上下文。电视端字体倍率固定为 1，文字随控件同比例变化。手机、触屏平板继续使用原来的适配逻辑。

720p、1080p、4K、8K 的缩放倍率分别为 1、1.5、3、6。这里使用 Android 实际交给应用的像素尺寸；某些 4K 电视可能仍以 1080p 渲染应用界面。相同宽高比下，控件占屏比例保持一致，在更大的物理屏幕上也随画面同比例变大。无需识别 65/70/75 英寸。

缩放只作用于 MainActivity 资源上下文，不修改系统或 Application 密度。电视分辨率变化会重建 Activity，以重新计算比例。非常规宽高比按较小倍率缩放固定尺寸，剩余区域仍由现有弹性布局填充。

## 验收

单元测试检查标准分辨率的逻辑画面尺寸、顶部栏和字体占比，并检查非常规宽高比的缩放边界。它不能替代电视上的实际显示验证。

安装 app/build/outputs/apk/debug/app-debug.apk 后，分别在原 65 寸电视和出现问题的 70/75 寸电视检查：

1. 首页顶部按钮、底部栏、左侧视频和右侧海报的相对位置及比例。
2. 搜索键盘、歌曲/歌星列表、设置、已点弹窗、调音弹窗的文字、边距及按钮是否完整。
3. 遥控焦点、点击位置、视频小窗/全屏切换及退出全屏后的布局。
4. 切换电视输出分辨率后重新打开应用，确认画面比例一致。

当前没有连接电视或模拟器，以上设备验收待完成。
