# 播放内核选择

## 实现

- 2.1.2 与 2.1.3 的播放器代码相同，使用 Media3 ExoPlayer 1.7.1 和 NextLib 1.7.1-0.9.0；2.1.4 改为自研原生 FFmpeg 播放链路。
- 设置 → 播放设置 → 解码器提供“自动（ExoPlayer 优先）”“ExoPlayer”“FFmpeg”。设置持久保存，下一首歌曲生效。
- 自动模式恢复 2.1.3 的 ExoPlayer 播放路径，包括 PCM 声道、音量、升降调、轨道选择和已有的有限解码恢复。该内核最终报错后，单向切换至当前原生 FFmpeg 内核。
- 固定 ExoPlayer 或 FFmpeg 模式不跨内核自动切换。
- 跨内核恢复保留进度、播放/暂停意图、原伴唱轨道选择、声道、音量和音调；停止、切歌、释放后拒绝过期回调。
- 当前播放内核可查看实际内核和初始化的解码器名称。ExoPlayer 内部可能使用系统 MediaCodec 或 NextLib 扩展，不能把内核名称直接当成硬解证明。
- 仅报错触发跨内核恢复，持续低帧率但不报错时需手动选择内核；未加入未经验证的卡顿自动切换阈值。

## 验证边界

- Debug APK 构建及 JVM 单元测试用于代码验证。
- 未连接真机或模拟器，尚未验证故障设备的流畅度、跨内核恢复及 KTV 双播放器同步；不能据编译结果宣称现场卡顿已解决。
- 不改版本号、签名、正式发行包或发布记录。Debug 应用包名为 `com.local.ktv.qa`。
- 原有 artifacts、诊断文件及 stash 保留。
