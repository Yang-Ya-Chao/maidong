# OpenList 网盘点播

对应需求：[Gitee issue IKL0GK](https://gitee.com/yangyachao-X/maidong-ktv/issues/IKL0GK)。实现位于 `feature/igeba-media` 分支。

## 使用方法

1. 在 OpenList 中挂载网盘，确认目标歌曲目录能够正常列出文件。
2. 麦动 KTV 打开「设置 → OpenList 网盘歌曲」，填写服务地址、访问令牌、歌曲目录及可选目录密码。
3. 服务地址填写设备能够访问的最终地址，例如 `http://192.168.1.10:5244`；支持反向代理子路径。令牌填写 OpenList 登录令牌，不添加 `Bearer` 前缀；允许访客读取的目录可以留空。
4. 选择「连接并保存」。连接成功后浏览目录，点击标有「点歌」的音视频文件即可加入已点队列。文件名沿用本地歌曲的「歌手-歌名」解析约定。
5. 每页最多列出 100 项，支持进入子目录、上级目录、上一页、下一页及重新加载。上级目录不会越过设置的歌曲目录。
6. 再次打开入口可修改或清除连接设置。更换服务器后，旧服务器的已点歌曲需要连接回对应服务器才能播放。

## 行为与范围

- 使用 OpenList `POST /api/fs/list` 列目录，播放前调用 `POST /api/fs/get` 获取 `raw_url`，通过现有 Media3 播放器在线播放。
- 每次开始播放及播放错误重试都重新获取地址；已点和已唱状态仅记录服务器与文件路径，不记录临时播放地址或访问令牌。
- 网盘歌曲复用现有队列、切歌、暂停、重唱、全屏及歌曲状态持久化。重启恢复时重新解析播放地址；切歌后忽略旧歌曲尚未完成的请求。
- 不递归导入整盘、不加入内置曲库全局搜索，不通过原有 i歌霸下载接口下载网盘歌曲。网盘内的文件不会被应用删除。
- 接入的是用户已经部署或可访问的 OpenList 服务，网盘账号挂载由 OpenList 管理。
- 部分网盘直链要求特殊请求头或客户端 IP，建议在 OpenList 中开启相应存储的代理播放/下载设置，并确保服务端可访问网盘资源。
- 原唱/伴唱能力取决于文件本身的音轨或左右声道；本版本未接入 OpenList 同目录的独立原唱、伴奏和歌词文件。
- 「重新加载」重新请求列表，不申请 OpenList 的强制刷新权限。

## 验证

新增 `OpenListSupportTest` 覆盖中文文件路径、目录边界、不同目录同名文件、歌曲序列化恢复、HTTP 分页参数、目录密码和令牌传递、播放地址重新获取、接口业务错误以及禁止令牌随重定向发送。

本机模拟接口测试不能替代实际网盘账号、服务部署、电视遥控器操作与音视频解码验收。
