# OpenList 与歌曲保存位置

对应 [IKL0GK](https://gitee.com/yangyachao-X/maidong-ktv/issues/IKL0GK)。修复与网盘需求已统一合并至 feature/igeba-media，包含固定 16:9、下载文件识别及 SD 卡发现。

## 使用

1. 在「设置 → 数据设置 → 网盘设置」填写 OpenList 地址、登录令牌、歌曲目录和可选目录密码。允许访客访问时令牌留空。设置仅检查连接，不打开目录浏览点歌页面。
2. 「歌曲保存位置」默认本地，可选择 U盘或 OpenList 网盘。选择网盘后，「U盘加歌」显示为「网盘加歌」。
3. 点击「立即加歌」，扫描已配置网盘歌曲目录及子目录；完整扫描后保存本机索引，支持原有主搜索、快捷搜索和手机点歌。扫描只保存索引，不批量下载媒体；失败保留上次完整索引。
4. 搜索结果中的「保存到」可选择本地、U盘、网盘。已有本地媒体可以上传网盘；网盘歌曲可下载到本地或 U盘。队列播放优先使用可用本地文件，否则临时解析网盘播放地址。

扫描与保存使用相同目录：本地 /storage/emulated/0/MaidongKTV/video/cloud-song、U盘 maidongktv/video/cloud-song、网盘配置的歌曲目录。U盘读取权限和挂载兼容修复已包含在同一分支。

## 曲库更新

启动只安装或打开 APK 内置 i歌霸曲库，不主动检查或同步曲库。数据设置中的「曲库 → 更新」主动检查 i歌霸目录版本；有变化则同步曲库，没有变化提示「曲库已是最新」。保留歌曲播放接口检查和独立 APK 更新检查，不从 Gitee 下载数据库。

## 接口与限制

使用 POST /api/fs/list 分页扫描，POST /api/fs/get 临时解析播放地址，PUT /api/fs/put 上传。上传成功还需确认目标文件长度；不覆盖已有同名文件。账号必须有目标目录上传权限，存储驱动也须支持上传。

下载网盘媒体要求服务返回 Content-Length；特殊请求头/IP 限制的网盘建议开启 OpenList 代理下载。上传 i歌霸在线媒体需要本机临时空间，成功或失败后清理暂存文件。网盘不参与本地缓存自动删除。长按歌曲可手动选择“删除本地文件”或“删除远端文件”：本地操作删除本机/U盘副本，远端操作通过 POST /api/fs/remove 删除该歌曲的 OpenList/NAS 原文件；确认框显示远端路径，本地副本保留。远端删除要求账号及存储驱动拥有删除权限，失败时保留索引；不支持删除目录或配置歌曲目录以外的文件。

网盘索引、已点与已唱状态不记录访问令牌或临时媒体地址。独立原唱、伴奏和歌词文件尚未关联，音轨/声道能力取决于媒体本身。

## 验证范围

单元测试覆盖路径边界、中文文件名、分页、配置恢复、播放地址解析、上传请求及错误处理、上传后长度确认和缓存索引恢复。Debug 构建通过。

Windows 已部署 OpenList v4.2.6，Local 驱动挂载 /KTV，模拟器连接 http://192.168.3.15:5244。测试媒体为自行生成的 120 秒 H.264/AAC 视频。此前版本已实测配置保存、中文目录读取和 Media3 在线播放；统一检索代码已在模拟器检索到该歌曲。新版完整上传下载流程、实体 U盘/SD 卡和第三方网盘仍需设备验收，不能用单元测试替代。

[官方接口文档](https://doc.oplist.org/api) · [文件读取源码](https://github.com/OpenListTeam/OpenList/blob/main/server/handles/fsread.go) · [文件上传源码](https://github.com/OpenListTeam/OpenList/blob/main/server/handles/fsup.go)

本地、U盘和网盘共用 LocalSongResolver：优先按曲库文件名匹配（忽略扩展名大小写），再按源编号匹配，匹配成功恢复歌名、歌手、语言和声道。数字媒体文件名不必等于源编号。手动歌曲使用歌手-歌名解析，歌名中的后续连字符保留。网盘旧索引加载时也重新关联当前曲库，避免旧数字标题覆盖曲库名称。应用下载的完成记录在数据库匹配失败时可恢复元数据。

2026-10-13 合并版本通过 57 项单元测试和 Debug 构建；模拟器本地页面显示数字缓存歌曲「后来／刘若英」「西海情歌／刀郎」，HL 检索命中「后来」；手动文件「测试歌手-OpenList连接测试.mp4」解析为歌名和歌手，OP 检索命中。实体 U盘/SD 卡挂载仍需真机验证。
