## 核心功能

- TV 遥控器全局导航，支持方向键、确认键、返回键和长按操作。
- 统一焦点反馈，按钮、列表、卡片、开关和弹窗均提供清晰的选中状态。
- 首页提供排行榜、歌名、歌星、常唱、收藏、分类和本地歌曲入口。
- 支持全网与本地歌曲检索、语种筛选、分页浏览和首字母键盘输入。
- 歌星页面支持头像标签分类和歌手歌曲浏览。
- 支持歌曲点播、批量点歌、置顶、收藏、取消收藏和文件管理。
- 已点、已唱和下载列表实时同步歌曲状态。
- 已下载歌曲直接加入队列；未下载歌曲完成下载后自动加入，不打断当前播放。
- 已点列表存在歌曲时自动开始播放，并在切歌后同步队列与播放状态。

## 播放功能

- 使用 AndroidX Media3 播放器处理本地和下载歌曲。
- 支持小窗播放与全屏播放，切换页面和执行点歌操作时保持视频连续播放。
- 支持播放、暂停、切歌、重唱、进度显示和拖动。
- 支持原唱与伴唱切换，并保持当前播放或暂停状态。
- 播放状态在小窗、全屏控制栏和提示浮层之间实时同步。
- 支持歌曲片头信息、播放提示和暂停常驻提示。
- 播放画面固定按 16:9 布局，支持自动全屏和音画同步设置。
- 支持歌曲最大音量及原唱、伴唱相关声音策略。

## 下载与数据

- 支持歌曲后台下载、进度展示、断点恢复和失败重试。
- 下载异常时校验文件完整性，支持重试和删除失败任务。
- 支持已下载歌曲识别、数量统计和本地文件播放。
- 内置新版歌曲、歌星、分类和排行榜曲库，首次启动即可查询。
- 存储权限完成后再启动目录创建、数据库扫描和下载任务。
- 默认使用本地存储，也可选择 U 盘或配置好的 OpenList 网盘作为保存目标。U 盘不可用或空间不足时自动回退本地。
- U 盘歌曲从所选卷的 `maidongktv/video/cloud-song` 目录扫描；网盘歌曲从配置的歌曲目录扫描。扫描建立本地歌曲索引，可在本地列表及检索框中查找和点播。
- 应用下载保存的数字编号文件优先按曲库中的文件名匹配歌名与歌手；外部拷贝的歌曲按 `歌手-歌名.扩展名` 解析，两种来源均支持检索。
- 预留空间提供遥控器可直接选择的容量档位；达到阈值后保护当前及已点歌曲，并按最近使用时间自动清理。
- 本地下载目录保持为 `/storage/emulated/0/MaidongKTV/video/cloud-song`；U 盘下载目录为所选卷根目录下的 `maidongktv/video/cloud-song`。

## 设置功能

- 数据设置：歌曲保存位置、网盘设置、手动曲库更新、本地扫描、预留空间、自动删歌和重置曲库；重置清除应用歌曲缓存并恢复内置曲库，不处理 U 盘文件。
- 播放设置：自动全屏、音画同步和片头字幕；画面固定按 16:9 布局。
- 声音设置：音量策略、歌曲最大音量及原唱伴唱策略。
- 界面设置：语言、悬浮按钮、轮播图和歌曲片头字幕。
- 设置弹窗支持临时选择、确认保存和关闭取消，遥控器焦点状态清晰可见。
- 启动时自动检查 Gitee Release；发现更高版本后可在应用内下载并启动系统安装器。

## 界面与交互

- 界面同时适配电视、横屏手机和平板；窄屏自动压缩栏高、留白、字号和播放器侧栏。
- 全屏播放右上角常驻小型手机点歌二维码。
- 顶部播放控制、小窗控制和全屏控制保持一致的状态与语义。
- 列表刷新、分页、标签切换和点歌后保持真实焦点位置，避免焦点跳动。
- 焦点选中仅改变颜色，不改变控件原有尺寸、圆角或布局。
- 使用麦动圆形 Logo，并在首页、播放页和应用信息中保持统一显示。

## 曲库与应用发布

- `app/src/main/assets/igeba_catalog.db`：内置歌曲、歌星、分类歌单和排行榜。
- `app/src/main/assets/singer_portraits.db`：独立歌星图片地址索引，图片加载需要访问对应地址。
- 个人歌曲快照保存在独立的 `personal_media.db` 中，收藏、歌单引用及设置由本地状态保存。
- 启动时使用 APK 内置曲库，不自动更新曲库，也不从 Gitee 拉取数据库。点击数据设置中的“曲库更新”，才主动检查 i歌霸曲库列表：存在变化则同步，没有变化则提示已是最新。
- “重置曲库”清理本机歌曲缓存和已下载歌曲，恢复 APK 内置曲库，不删除 U 盘文件。
- 应用更新以 Gitee Release 标签作为版本号，例如 `2.1.0`；发布页面需附带 `.apk` 文件。只有标签版本高于当前版本时，应用才提示更新。应用版本检查与曲库更新是独立功能。

## U 盘使用

1. 插入 U 盘，在数据设置中选择 U 盘存储；有多个卷时选择对应卷，不需要手动挑选子目录。
2. 下载保存使用所选卷的 `maidongktv/video/cloud-song` 目录。手动拷贝歌曲也放入该目录，使用“U 盘加歌”中的“立即加歌”扫描。
3. 扫描完成后显示新增歌曲数量；扫描到歌曲后可以进入本地列表点播。
4. 默认使用本地存储。选择 U 盘后，如果未插入、不可写或空间不足，当前下载回退本地；保留 U 盘偏好，重新可用时后续任务可以继续使用 U 盘。

系统已挂载且应用可读取的可移除内存卡同样参与卷识别。不同设备的挂载与写入权限可能不同，详见 [U 盘与内存卡说明](docs/usb-song-import.md)。

## OpenList 网盘使用

1. 在“设置 → 数据设置 → 网盘设置”填写 OpenList 服务地址、访问凭据和歌曲目录，并测试连接。模拟器连接本机服务时使用可达的宿主机地址，不能用模拟器自身的 `127.0.0.1`。
2. 将歌曲保存位置选为网盘，“U盘加歌”入口随之显示为“网盘加歌”。点击“立即加歌”，递归扫描配置目录并添加到本地歌曲索引。
3. 扫描后的网盘歌曲与本地、U 盘歌曲一起参与检索和点播；扫描只建立索引，播放时从网盘读取歌曲。
4. 搜索结果中选择“保存到”，可将歌曲保存到本地、U 盘或网盘。网盘保存需要 OpenList 账户具有目录上传权限。

三种位置统一识别应用编号文件与 `歌手-歌名` 文件。详细配置、权限及连接测试见 [OpenList 设置说明](docs/openlist.md)。
